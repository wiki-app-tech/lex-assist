# 📚 lex-assist

> Consulta, lectura y resumen inteligente de Boletines Oficiales, leyes, decretos y circulares para asistencia administrativa.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

## ✨ Características

- 🔍 Búsqueda semántica sobre normativa oficial de Tierra del Fuego, Argentina.
- 🧠 Resúmenes automáticos con LLMs (locales o API).
- 📅 Alertas por tema, organismo o palabra clave.
- 🌐 Multi-fuente: Boletín Oficial TDF, Legislatura, Tribunal de Cuentas, etc.
- 🔗 Trazabilidad: cada resumen cita su fuente original.

## 🚀 Inicio rápido

```bash
git clone https://github.com/wiki-app-tech/lex-assist.git
cd lex-assist
cp .env.example .env
docker compose up -d
```
